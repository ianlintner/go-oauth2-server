# go-oauth2-server

Go port of [`rust-oauth2-server`](https://github.com/ianlintner/rust-oauth2-server), developed against the shared cross-language conformance fixtures used by [`typescript-oauth2-server`](https://github.com/ianlintner/typescript-oauth2-server).

**Status:** architecture proposal only. No server code exists yet, and nothing here is spec-compliant or production-ready. See [`docs/architecture-proposal.md`](docs/architecture-proposal.md) for the planned stack, stages and conformance approach.
